# Papers

Local copies of the research papers cited in the blog. We keep them here so the project is self-contained for offline reading and so direct citations can link to fixed PDFs rather than potentially-moving URLs.

| File | Citation | What's in it |
|---|---|---|
| `tibshirani_2011_darts.pdf` | Tibshirani, R. J., Price, A. & Taylor, J. (2011). *A Statistician Plays Darts*. JRSS Series A, **174**(1), 213–226. | The foundational paper. Defines the `Z = μ + ε, ε ~ N(0, Σ)` model, gives the EM algorithm for fitting Σ from scores only, and reports the σ values for two human authors (one weak, one decent). §3 derives the full-Σ extension; §4.2 / Figure 5 shows the optimal-aim heatmaps for σ ∈ {5, 26.9, 64.6} mm. |
| `tibshirani_significance.pdf` | Tibshirani, R. J. (2011). *Don't try for the triple 20*. Significance **8**(1), 46–48. | Popular-audience version of the same work. Restricts to the isotropic-σ case and is the source of the canonical three-tier σ = {5, 25, 60} mm rule of thumb. Useful as the "explain it like I'm not a statistician" citation. |
| `haugh_wang_2022_dp_darts.pdf` | Haugh, M. B. & Wang, C. (2022). *Play Like the Pros? Solving the Game of Darts as a Dynamic Zero-Sum Game*. INFORMS Journal on Computing **34**(5), 2540–2551 (arXiv:2011.11031). | Extends Tibshirani's model to **target-region-dependent** Σ: one Σ_m per target region m ∈ {T20, T19, T18, T17, DB, all-doubles}. Solves the full 501 game as a zero-sum dynamic game over the action set of 90,785 possible aim points. The numerical Σ fits for 16 PDC top-16 pros are *not in the paper* but live in `OptimalDarts_repo/ALL_Model_Fits.mat`. |
| `haugh_wang_2024_eb_darts.pdf` | Haugh, M. B. & Wang, C. (2024). *An Empirical Bayes Approach for Estimating Skill Models for Professional Darts Players*. arXiv:2302.10750. | Hierarchical extension of the same model. Estimates *both* μ (where the player actually aims) and Σ (their error covariance). Crucial reading for §7.1, which proves that **the off-diagonal element of Σ is not identifiable from score data alone**: the fitted ellipse orientation is mostly an artifact of the region's geometry. Also contains the most cited quantitative evidence for *target-dependent skill* (Table 5 p. S-5: average bias |μ − region center| varies from 1.5 mm at T20 to 5.2 mm at T17 across the 16 pros). |
| `OptimalDarts_repo/` | https://github.com/wangchunsem/OptimalDarts | Code + data accompanying the two Haugh & Wang papers. The MATLAB file `ALL_Model_Fits.mat` contains the 96 covariance matrices (16 pros × 6 target regions) referenced throughout. `Raw_Data.xlsx` is the underlying score counts. |
